iMD setup guide

How to Download and Install iMD

Choose the access route for your device below. An active subscription is required, and support provides your iMD credentials after activation.

Instructions by device

How to download iMD on your device

These are the current access and download options described by this website. If your device setup is not listed, contact support before installing anything else.

iOS

iPhone and iPad

Open iMD web to access the service. Sign in with the details provided after your subscription is activated.

Open iMD web
Android

Android phones and tablets

Download the APK and open it on your device. If Android asks for permission to install it from your browser, follow that prompt, then open the app.

Download the Android APK
Windows

Windows PC

The current guide uses an Android emulator. Install an emulator, then open the iMD APK inside it.

Get an Android emulator Download the Android APK
macOS

MacBook and iMac

This website does not list a separate macOS installer. Use the iOS access route on a supported Apple device or ask support about current Mac options.

Ask iMD support

First-time setup

Install, activate, and log in

Follow these steps using the device instructions above.

  1. 01

    Choose a subscription plan

    Review the available durations and contact the team to arrange access. Payment is handled manually.

  2. 02

    Install or open iMD

    Use the route listed for your device. Enter an activation code only if the app asks for one.

  3. 03

    Log in with your access details

    After activation, use the credentials supplied by support. If you need help, see the member login help.
